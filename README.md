# 📊 Credit Score Classification

A Machine Learning project for predicting credit score categories based
on financial and credit-related features.

------------------------------------------------------------------------

## 📌 Project Overview

Credit scoring is a crucial task in the financial industry. Banks and
financial institutions use credit scores to evaluate an individual's
creditworthiness before approving loans or credit cards.

This project applies supervised machine learning algorithms to classify
individuals into different credit score categories using structured
financial data.

------------------------------------------------------------------------

-   Exploratory Data Analysis (EDA)
